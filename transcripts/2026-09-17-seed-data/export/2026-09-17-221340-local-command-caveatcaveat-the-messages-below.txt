  npm run whoami --prefix backend -- <paste token>
  It prints one line, something like auth0|62e0…. The token is only decoded on
  your machine; nothing is sent anywhere.

  Step 3: put the sub in backend/.env, which is gitignored, so it won't be

  Your .env was created before this change, so the line isn't there yet. Add it
  yourself.

  Step 4: load the demo data. There's a catch here. A normal seed only fills an

  your account, which I saw when I ran the seed earlier, so restarting dev will
  skip you and print Owner A: already has data, left alone. You have two
  options:

  - Wipe your rows and load the demo data:
  npm run db:seed:reset --prefix backend
    This deletes everything you own locally (and B's rows) and rebuilds the demo
    set. It only works against the local Docker database.
