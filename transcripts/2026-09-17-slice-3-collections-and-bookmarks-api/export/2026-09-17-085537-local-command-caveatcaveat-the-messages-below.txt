❯ what does scrub mean?                                                         

⏺ "Scrub" means removing sensitive details from a session log before it's
  committed. The repo is public and the logs are committed as a deliverable, so
  they have to be cleaned first.

  The repo has a script for it, transcripts/scrub.py. According to DECISIONS.md
  ("Transcripts"), it replaces these with placeholders:

  - Email addresses, such as yours in git config or in the Auth0 login.
  - JWT-shaped strings, meaning access tokens. A token that hasn't expired is a
    working credential for the API.
  - OAuth sign-in values: code, state and code_verifier from the sign-in
    redirect.
  - Absolute home paths like /Users/<you>/…, which reveal your username and
    machine layout.

  It exits with an error if anything matching those patterns is still there
  afterwards. It only matches patterns, so a person should still skim the log
  before committing it.

  CLAUDE.md's rule is: never commit unscrubbed transcripts, and run python3 
  transcripts/scrub.py on logs first. That's why I left
  transcripts/2026-09-17-slice-2-token-guard/ out of the commit.

  commit it once you've looked?
