  Setting up Testcontainers with Colima

  Your Docker runs in Colima, and its socket isn't where Testcontainers looks by
  default. Two settings fix that:
  - DOCKER_HOST tells Testcontainers where Colima's Docker socket is on your
    Mac.
  - TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE gives the path of that socket inside
    the Colima VM. Testcontainers needs it for its cleanup container (Ryuk), and
    inside the VM the socket is at the usual /var/run/docker.sock.

  Option A: shell profile (recommended). Add these two lines to ~/.zshrc:

  export DOCKER_HOST="unix://$HOME/.colima/default/docker.sock"
  export TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock

  Then open a new terminal, or run ! source ~/.zshrc here, and run the tests
  with npm test.

  Setting DOCKER_HOST also changes which daemon the docker CLI uses. That's
  harmless here, because your active Docker context is already Colima.

  Option B: Testcontainers' own config file. If you'd rather not set DOCKER_HOST
  for your whole shell, create ~/.testcontainers.properties:

  docker.host=unix://~/.colima/default/docker.sock

  As far as I know, the socket override can only be set as an environment
  variable, so you'd still add the second export line to ~/.zshrc.

  These are settings for your machine, so they stay out of the repo. If you
  want, I can add a short "Running tests on Colima" note to the README once it
  exists.
